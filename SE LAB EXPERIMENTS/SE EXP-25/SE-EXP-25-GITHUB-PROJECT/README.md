# SE-EXP-25-GITHUB-PROJECT

## Project Description

This repository demonstrates Git and GitHub version control operations for Software Engineering Lab Experiment 25.

## Objectives

- Create a GitHub repository
- Clone the repository locally
- Modify project files
- Stage and commit changes
- Push changes back to GitHub

## Technologies Used

- Git
- GitHub
- Markdown

## Experiment

This experiment demonstrates the basic Git workflow:

Clone → Edit → Stage → Commit → Push
