# SE EXP-20 - GitHub Version Control

## Project Title
Team Project Version Control Demonstration

## Objective
To implement GitHub-based version control using branches, pull requests,
code reviews, merging, conflict resolution, and README documentation.

## Modules
- Module 1: User Interface
- Module 2: Data Processing
- Module 3: Testing

## Git Workflow
1. Develop modules using separate branches.
2. Commit and push changes to GitHub.
3. Create pull requests for code review.
4. Review and merge approved changes into main.
5. Resolve merge conflicts when they occur.
6. Maintain project documentation using README.md.
